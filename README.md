# Генератор чеков платной автостоянки

Python-скрипт для автоматической генерации PDF-чеков для платной автостоянки на основе данных из CSV/JSON файлов и HTML-шаблонов.

## Структура проекта

```
PRG3/
├── data/                    # Файлы с данными (CSV, JSON)
│   └── parking_data.csv    # Тестовые данные
├── templates/               # HTML-шаблоны для чеков
│   └── invoice_template.html
├── output/                  # Генерированные PDF-файлы
├── venv/                   # Виртуальное окружение
├── generate_invoice.py      # Основной скрипт
├── requirements.txt         # Зависимости проекта
└── README.md               # Документация
```

## Установка

1. Убедитесь, что у вас установлен Python 3.7 или выше
2. Активируйте виртуальное окружение:
   - Windows PowerShell: `.\venv\Scripts\Activate.ps1`
   - Windows CMD: `venv\Scripts\activate.bat`
   - macOS/Linux: `source venv/bin/activate`
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

1. Запустите скрипт:
   ```bash
   python generate_invoice.py
   ```

2. Следуйте инструкциям в консоли:
   - Выберите файл с данными (CSV или JSON)
   - Выберите HTML-шаблон
   - Выберите номер чека (invoice_id) для генерации
   - PDF автоматически создастся и откроется

## Формат данных

### CSV файл

CSV файл должен содержать следующие колонки:
- `invoice_id` - уникальный номер чека
- `brand` - марка автомобиля
- `model` - модель автомобиля
- `color` - цвет автомобиля
- `registration_number` - государственный номер
- `entry_date` - дата въезда (YYYY-MM-DD)
- `entry_time` - время въезда (HH:MM:SS)
- `exit_date` - дата выезда (YYYY-MM-DD)
- `exit_time` - время выезда (HH:MM:SS)
- `price_per_hour` - цена за час парковки
- `total_amount` - итоговая сумма к оплате

### JSON файл

JSON файл должен содержать массив объектов с теми же полями, что и CSV:
```json
[
  {
    "invoice_id": "1",
    "brand": "BMW",
    "model": "320i",
    "color": "Черный",
    "registration_number": "А123БВ77",
    ...
  }
]
```

## HTML-шаблоны

HTML-шаблоны используют синтаксис плейсхолдеров: `{{ field_name }}`

Пример: `{{ brand }}`, `{{ model }}`, `{{ registration_number }}`
